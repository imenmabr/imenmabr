### 02 — Autonomous Navigation

**Complete Autonomous Navigation Stack**

Nav2, AMCL, global and local planning, costmaps, behavior trees, recovery behaviors, dynamic obstacles, and navigation benchmarking.

**Status:** Planned

---

### 03 — SLAM Evaluation

**SLAM Benchmark**

Comparative evaluation of SLAM Toolbox, Cartographer, and RTAB-Map using the same robot, LiDAR, and simulation environment.

Evaluation criteria will include:

* Mapping accuracy
* Execution speed
* CPU utilization
* Memory utilization
* Map quality
* Navigation usability

**Status:** Planned

---

### 04 — Robot Localization

**Localization Laboratory**

Comparison of wheel odometry, AMCL, and EKF-based localization using `robot_localization`.

The project will analyze drift, localization error, sensor noise, loss of localization, and recovery performance.

**Status:** Planned

---

### 05 — Multi-Sensor Fusion

**LiDAR–Camera Sensor Fusion**

A complete ROS 2 pipeline covering sensor calibration, coordinate transformations, data synchronization, LiDAR projection, object association, and experimental evaluation.

**Status:** Planned

---

### 06 — Robot Perception

**ROS 2 Robot Perception**

Object detection and tracking pipeline integrating computer vision models with ROS 2 topics, visualization, and LiDAR information.

**Status:** Planned

---

### 07 — Integrated Autonomous Robot

**Complete Autonomous Mobile Robot**

Integration of:

* Robot modeling
* SLAM
* Localization
* Autonomous navigation
* LiDAR perception
* Camera perception
* Object detection
* Sensor fusion

**Status:** Planned

---

### 08 — Learning-Based Navigation

**Deep Reinforcement Learning for Mobile Robot Navigation**

Evaluation of DQN and Attention-DQN approaches for mapless mobile robot navigation using LiDAR observations.

**Status:** Planned
